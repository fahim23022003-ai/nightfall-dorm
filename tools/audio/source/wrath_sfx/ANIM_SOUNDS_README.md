# anim-sounds — คลังเสียงฟรี CC0 สำหรับทำคลิป

คลังเสริมของ [anim-mobile-template](https://github.com/S3Electronics/anim-mobile-template) : เสียงประกอบ 306 ไฟล์ + เพลง 37 ไฟล์

- ทุกไฟล์เป็น CC0 (public domain) จาก Freesound ผ่าน Openverse ใช้ได้ทุกงาน รวมถึงเชิงพาณิชย์ ไม่ต้องให้เครดิต
- ทำความดังให้เท่ากันแล้ว (SFX -16 LUFS, เพลง -20 LUFS) เป็น mp3 ; SFX ตัดไม่เกิน 10 วิ เพลงไม่เกิน 90 วิ
- อยู่บน GitHub เพื่อให้ Claude Code บน cloud (เน็ตจำกัด) โหลดได้ผ่าน raw.githubusercontent.com

ใช้จาก repo ต้นแบบ:
```
node tools/find-sound.mjs ไก่ขัน
node tools/find-sound.mjs get rooster_1
```
