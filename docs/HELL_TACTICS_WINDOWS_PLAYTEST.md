# Windows x64 Hell Tactics Playtest

Extract the entire archive into an empty folder. Run **Play Hell Tactics
Preview.cmd** to use the V2 maps, Full Room Grid, Phase 14F art and the Hard
and Hell Campaign tactics. **Play Procedural V1 Fallback.cmd** and **Play
Fixed Reference.cmd** open comparison modes. Each launcher has a separate
playtest profile and leaves your normal save profile available.

## Test a Campaign match

- Start a Hard or Hell Campaign stage. Note the stage, room and overview seed.
- Build a concentrated defense, then try another room and defense mix. Watch
  whether the Hunter commits when it is breaking a door, or reroutes when
  another breach is more promising. Listen for and read its tactical cues.
- Stay with a match through defeat or victory. Check Hunter travel around
  walls, closed doors, retreat to a Haunted Hall, and the return to combat.
- In a boss encounter, observe transformation, phase changes and Crimson
  Execution. Compare a Standard match for the original siege behavior.
- Record graphics preset, GPU and any timing or readability issue with the
  seed and approximate time. Include a screenshot or clip if possible.

The package is a Windows x64 export. Linux Godot verifies the embedded
resources, launch mode rules and the fixed and V1 fallbacks. Native Windows
and Intel UHD performance require a Windows playtest.
