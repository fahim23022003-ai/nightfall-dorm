# Actual visual-overhaul captures

These PNGs are actual rendered game viewports, not AI-generated mock screenshots. The original **sprite atlas** was generated for this project; the images here were captured only after integrating those assets into the running Godot game.

Logical design: 1280×900. Native captured viewport: 1137×800 on Xorg/Mesa. Fixed-seed automated runs claim/position/sleep the player as a disclosed setup, then use ordinary starting money and real purchase/combat rules. Engine time is 4×. No resources, enemy damage or terminal outcomes are fabricated. Combat frames briefly pause real reached states. See [raw log](../../evidence/visual_overhaul/rendered-matches.log) and [report](../../VISUAL_OVERHAUL_REPORT.md).
