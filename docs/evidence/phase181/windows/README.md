# Windows x64 playtest archive

Extract the entire archive, then launch **Play Building Scale Preview.cmd**.
The preview reads and writes the separate Building Scale profile. **Play
Close Quarters Preview.cmd** remains available for the original rules.

The archive contains the Windows x64 executable, its embedded Godot
resources, the launcher scripts, and the license files. The ZIP entries
passed CRC verification. Linux Godot executed the embedded pack across
the preview modes. The Building Scale mode passed 60 Campaign and 30
Story Ready and fresh-match checks. Native Windows and Intel UHD remain
unverified.
