## Reproduce

Set `NIGHTFALL_CLOSE_QUARTERS=1`, `NIGHTFALL_PROCEDURAL_MAPS_V2=1`, `NIGHTFALL_FULL_ROOM_GRID=1`, `NIGHTFALL_WEAPON_FEEDBACK=1`, `NIGHTFALL_VISUAL_REBIRTH=1`, `NIGHTFALL_LIVING_NIGHTMARE=1` and `NIGHTFALL_SURVIVOR_REBIRTH=1`. Use `NIGHTFALL_BUILDING_SCALE=0` for the old rules and `1` for the enlarged rules. A real graphics display is required for render evidence.

```sh
godot --path . --resolution 1280x720 --audio-driver Dummy \
  --script res://tools/phase181/visual_capture.gd -- /tmp/nightfall-visual photos
```

The same command accepts `film`, `bench-standard`, `bench-low` and `validate` in place of `photos`. The paired plates are generated by `tools/phase181/visual_gallery.py`.
