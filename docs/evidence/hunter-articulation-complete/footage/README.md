# Ordinary Hunter combat captures

Godot rendered these encounters at 1280×720. Each clip is encoded at
the capture step of 24 frames per second and shows real-time game
movement. The fixtures set the Hunter level and a legal hallway route
before an ordinary paid Needle and door fight. Clip chapters identify
the evolution level.
