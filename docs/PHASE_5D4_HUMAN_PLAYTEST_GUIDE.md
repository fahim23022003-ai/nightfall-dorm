# The Reaper’s Wrath — owner and Adie playtest guide

This guide will be finalized with the verified Windows test build. Native Windows
and subjective usability, sound and difficulty are not validated by Linux tests.
Keep a backup of your existing profile and use a separate test profile if trying
potentially destructive save experiments. Ordinary play should preserve progress.

## Human acceptance questions

- Can a first-time player identify Gold, Electricity, their door, the Hunter and
  the next useful action without instruction?
- Can you build, upgrade, compare a branch and sell from one predictable area?
  Does the branch make a visible mechanical difference?
- Does a no-turret Hell run require meaningful defense, rather than waiting for
  allies to win? Compare with active defenses on the same map/archetype.
- Does each Hunter ability have a recognizable warning and a useful response?
- When a survivor dies, can you read and hear the exact evolution buff?
- In an eligible boss encounter, can you recognize both Reaper forms and react
  to summons, theft, curses and scythe attacks?
- Can you survive or win the final crimson encounter through actual decisions?
- Are Flame, Frost, Shock, Auto Repair, Shield and Decoy useful for different
  reasons, with understandable costs and limitations?
- Are Needle and Arc shots, hits, upgrades and boss warnings audible without
  overwhelming the existing music? Test your saved volume settings as well.
- Do teammate spectating, Return to My Room, saves, rewards and ordinary modes
  still behave as expected?

Record map, difficulty, stage/wave, archetype, build, unused items and the moment
of a problem. A screenshot or short recording is useful; subjective feedback is
welcome even when automated checks pass.
