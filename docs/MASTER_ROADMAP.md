# Nightfall Dorm master roadmap

## Phase 23 · Hunter intelligence and fair balance

The Story preview recognizes fire along a route, distinguishes door upgrades from recurring repair, and can resume an approach interrupted by a Haunted Hall visit. Matched Godot trials include all ten chapters. A skilled item-free policy won eight of twenty Hell starts. Two passive wins on one held-out map and more repeat visits remain playtest concerns. [Release, gameplay footage and balance evidence](evidence/phase23/README.md)

## Phase 22.1 · Targeted UI polish

The preview narrows the Build drawer, increases decision-text sizes and uses the same opening Hunter name from Story preparation through gameplay. Linux Godot measured faster Build draws at both presets. Low tutorial p95 improved in the staged replay, while long frames and cold entry still need investigation. Native Windows timing awaits a playtest.

[Release, walkthrough and measured results](evidence/phase221/README.md)

## Phase 22 · Desktop interface refinement

The Windows preview adds categorized construction, a machine inspector with quoted refunds, compact single-choice tutorial lessons, session-aware menus and a critical-door defense shortcut. Native Linux input tests and packed Windows-resource checks passed. The larger catalogue still costs more than Phase 21 in software rendering. Owner Windows performance and usability review remain open.

[Playtest build and evidence](evidence/phase22/README.md)

## Phase 21 — Tactical Interface

The desktop preview combines one status bar, a four-action dock, one
placement tool, categorized settings and a lighter three-lesson practice
flow. Phase 20 remains the owner-played reference. Review the recorded
comparisons and native performance limits before promoting the preview.
[Visual and performance evidence](evidence/phase21/README.md)

## Owner-approved project — Full room grid building

The owner authorized the grid preview while artistic review and native
Windows testing of Phase 14F are pending. Review the combined build through
the [Full Room Grid preview](FULL_ROOM_GRID_PREVIEW.md).

- Divide the entire usable room floor into buildable grid cells. Allow
  placement anywhere a building footprint fits on valid tiles.
- Replace progressive 3/6/8/10/16 slot unlocking and arbitrary slot-cap
  progression with physical floor constraints.
- Give different building types appropriate physical footprints. Validate
  placement, movement and rotation against walls, doors, room fixtures,
  actors and neighboring buildings.
- Preserve safe access and pathfinding through rooms. Measure navigation,
  rendering and input under dense valid layouts.
- Design and verify save migration for existing buildings, ownership and
  progression. Handle layouts that do not fit the grid without deleting
  saved investments.
