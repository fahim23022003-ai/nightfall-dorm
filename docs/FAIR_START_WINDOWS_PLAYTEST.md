# Nightfall Dorm V2.3 Windows playtest

Extract the whole ZIP into an empty folder, then open **Play Fair Starting
Rooms Preview.cmd**. This launcher enables Phase 14F visuals, Full Room Grid,
and V2 procedural maps. Hard and Hell Campaigns exercise the updated siege
decisions. Use either fallback launcher to compare V1 or fixed layouts.
All three profiles are separate from your regular saves.

## Opening checks

- In a Hard or Hell Campaign, press **M** and select a vacant room before
  claiming it. A short first Hunter approach is highlighted as **Fast Hunter
  Route**. Record the stage, seed, room, and Hunter archetype.
- Run one opening with an empty item loadout. Try buying Bed 2 and saving
  straight through to Bed 3 before adding Door 2 and a Needle on the approach.
  Use paid repair after a hit leaves enough missing HP to absorb the repair.
  Compare another room or an early turret-first opening.
- Watch whether the Hunter keeps breaking a productive door or leaves after a
  successful defense. Try a new route, a Haunted Hall trip, both Grim Reaper
  forms where available, and the Full Room Grid build and move controls.
- Run a separate earned-item match if you want to compare consumables. Include
  your graphics setting, GPU, frame rate, and any screenshot or clip when reporting.
  Check both Standard and Low in a crowded room.

Campaign generates a fresh seed. The repository's deterministic capture shows
the exact Stage 2 Hell Labyrinth 10358 Room 2 fixture. An Endless seed can
reproduce its geometry with the same theme, with Endless combat rules.

The archive contains a Windows x64 executable. Its embedded Godot pack and
launcher profiles were verified on Linux. Native Windows execution and Intel
UHD performance require a Windows playtest.
