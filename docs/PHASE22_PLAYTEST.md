# Nightfall Dorm · Phase 22 Windows playtest

Extract the entire ZIP, then double-click **Play Phase 22 Preview.cmd**. The game starts at 960×540 on Low with a separate Phase 22 test profile. The bundled **Play Performance Preview.cmd** uses the established Performance settings and its own profile.

- Open **Build [B]**, compare machines within a category and choose one. Rotate with **Q**. Click valid floor to place, or press **Esc** to cancel.
- Select an owned machine to inspect its output and upgrade. Review the refund before confirming a sale.
- Open **Items [I]** to inspect equipped items. Item use requires a separate action. **R** buys repair when eligible and **F** activates the Ward when eligible.
- Open the survival guide with **G**. **Esc** resumes play. Access Settings through **More**.
- Replay the three practice lessons to check movement, claiming a room, sleeping and purchasing a Dynamo and a Needle. Practice runs separately from permanent progression.
- For Windows timing, launch **Record Phase 22 Diagnostic.cmd**, reproduce the slow scene, then press **F10**. Compare the same resolution, quality, room, camera and machine count. Native Windows and Intel UHD performance await owner testing.
