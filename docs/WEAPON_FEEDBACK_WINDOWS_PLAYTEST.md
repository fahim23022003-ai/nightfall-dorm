# Nightfall Dorm Weapon Feedback Windows playtest

Extract both downloads together. Run **Join and Extract.cmd**, then
**Play Weapon Feedback Preview.cmd**. Use **Play Phase 16 Preview.cmd** for
comparison. Both use your existing Living Nightmare preview profile. Close
one launcher before opening another.

- Buy a Needle Turret in a defended room. Watch its launcher, the dart in
  flight, the spark and floating number at contact, and the Hunter's HP.
- Mix Needle, Arc, Flame, Frost and Shock. Look for the different shot shapes
  and for separate **BURN** numbers. A guarded or fully shielded contact
  reads **IMMUNE** or **BLOCKED**. Select a machine to see its last effective
  hit and total damage.
- In Settings, compare **All**, **My weapons**, **Combined** and **Off**.
  Low graphics retains weapon fire, impact feedback and damage numbers.
- Try both graphics modes at 1280×720 in an active defense. Record the
  actual Windows GPU name and capture frame timings if available.

The package was exported with Godot 4.6.3 and verified by loading its
embedded game on Linux Godot. Native Windows and Intel UHD are untested.
