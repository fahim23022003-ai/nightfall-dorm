# Nightfall Dorm · Phase 22.1 Windows preview

Extract the full archive, then double-click **Play Phase 22.1 Preview.cmd**. The launcher starts at 960×540 on Low in a separate Phase 22.1 test profile. **Play Performance Preview.cmd** runs the existing fallback with its own profile.

Use **B** during a siege to check that Build leaves the room and door visible. Browse the four categories, choose a machine, and press **Esc** to cancel placement. Inspect an owned machine and review its upgrade cost and sale refund. Use **R** for repair and **F** for Ward where available.

Replay the three tutorial lessons and compare responsiveness with your normal Story play. For a frame report, use **Record Phase 22.1 Diagnostic.cmd**, reproduce the slowdown, then press **F10**. The embedded resources were tested in Linux Godot. Native Windows and Intel UHD timing await a hardware playtest.
