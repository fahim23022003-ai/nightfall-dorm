# Phase 19 · The Living Dorm

Extract the Windows x64 ZIP and open **Play Phase 19 Preview.cmd**. The
preview starts in Low at 960×540 with a separate test profile. **Play
Performance Preview.cmd** uses the previous gameplay and HUD flags for
comparison. It uses the existing Performance Preview profile.

The bottom door button shows live HP, maximum HP and percentage. The meter
turns amber and then crimson as the door weakens. **Repair [R]** shows the
cost or reason repair is unavailable. The objective card reports actual HP
recovered after a successful manual repair. Expand **Room effects** for the
room's bonuses and drawbacks. **Items [I]** opens the separate drawer.
Select an item to read its effects, then press **Use selected item** to spend
it. Escape closes the drawer.

The preview uses the established map routes and expanded machine footprints.
On fresh generated layouts, fixtures can move to a verified wall-side spot.
Saved layouts retain their serialized fixture positions. Amber areas in the
construction plan denote access reservations. The gothic door uses a compact
atlas with ten levels and two existing specialization paths.

The Hunter samples tactically comparable reachable rooms using the seed, then
commits to productive sieges. The map score palettes use different existing
recorded arrangements. New compositions are outside this preview. Boss,
heartbeat and outcome priorities are preserved.

The Stalker Shadowling pilot is disabled from the Windows launchers. It can
be tested independently in an isolated source run with
`NIGHTFALL_MINI_HUNTERS=1` and `NIGHTFALL_LIVING_DORM=1`. It uses a cap of six,
live attacks and weapon damage. Existing Endless intermission saves remain
on the reviewed rules, and Campaign still saves progression instead of an
active combat snapshot.

Run **Record Phase 19 Diagnostic.cmd** to start a local isolated report.
Press **F10** to save it and open its folder. Phase 19 Windows frame pacing
remains pending on the owner's PC.
